### 3.1 诊断：问题不在"多"，在于三种用途混在一起

| 类型 | 现在的例子 | 特征 | 该不该持续维护 |
|---|---|---|---|
| **参考手册** | 01 / 05 / 06 / 07 | 描述当前事实，代码改了必须同步 | ✅ 必须 |
| **教材** | 08（3,943 行）/ 11 / 12 / 13 | 讲原理，与代码版本无关 | ❌ 不必 |
| **留档** | 09 §5（347 行）/ 10 §6 / 14 | 只增不改，**必然腐烂** | ❌ 不该 |

混在一起的后果：读者判断不出"这段要不要信"，作者判断不出"这段要不要改"。

## 5. P2 上线设计

### 5.1 选型

实测依据：运行态四容器合计约 **200 MB** 内存（webapi 145 / nginx 17 / PG 33 / redis 8）；
镜像 webapi 386 MB、nginx 93 MB、PG **1.98 GB**。**瓶颈只在"构建"**（.NET SDK + npm ci + vite build），不在运行。

| 方案 | 配置 | 参考价 | 判断 |
|---|---|---|---|
| **A（推荐）** | 阿里云香港轻量 2核2G / 60GB / **30Mbps** | ≈408 元/年 | 免备案；本地构建镜像传上去，2 GB 够跑 |
| B | 阿里云香港轻量 2核4G / 80GB / 30Mbps | ≈804 元/年 | 可直接在服务器构建，最省事 |
| C | 腾讯云 2核2G **1Mbps** | 199 元/年 | ❌ 1 Mbps ≈ 128 KB/s，带图片的博客不可用 |

**为什么香港**：内地节点用域名必须 ICP 备案（等 1~2 周）；香港免备案，内地访问 70~120 ms，个人博客可接受。

### 5.2 关键决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 镜像交付 | 本地构建 → `docker save` → `scp` → `docker load` | 服务器无需 SDK/Node，2 GB 也能跑；PG 镜像 1.98 GB 只传一次 |
| 代码获取 | `git clone`（仓库 public） | 不需要 deploy key |
| HTTPS | 域名 + Let's Encrypt（certbot webroot）+ 自动续期 | 免费、可自动续期 |
| 回滚载体 | Git tag + 镜像 tag（`blog-webapi:<tag>`） | 关闭缺口 G4 |

### 5.3 部署 Runbook（每步带验收命令）

1. 购买（Ubuntu 24.04 LTS）→ 控制台防火墙只放 22 / 80 / 443
2. 首次登录加固：SSH 公钥、禁密码登录、`ufw`
3. 安装 Docker + compose 插件
4. `git clone` + 生成 `.env`（`openssl rand -base64 48`）
5. 传镜像（或服务器构建）
6. `docker compose up -d` → 验 `/health`、SPA 深链、登录、上传、检索
7. **立即修改管理员密码**（因为原密码在公开仓库里）→ 用旧密码登录**必须失败**
8. 域名 A 记录 → certbot 签证书 → 验 HTTPS 与自动续期
9. 备份：`pg_dump` 定时 + media 卷 → **并做一次恢复演练**（不演练的备份等于没有）
10. 回滚预案：镜像 tag + 迁移不可逆性说明

**产出**：`tools/deploy/`（脚本）+ `docs/05-运维与部署手册.md` 的部署章 + 一份真实上线记录。

## 7. P4 学习路线设计

`learn/README.md`：**6 个阶段**，每阶段 = 目标 + 读什么 + **动手任务** + **可验收的产出**。

| 阶段 | 验收标准（不是"读完就行"） |
|---|---|
| S0 跑起来 + 看懂一条请求 | 能口述中间件顺序，并说出 3 个顺序错误的后果 |
| S1 上线 | 一个可访问的 HTTPS 地址 + 能画出部署拓扑 |
| S2 压测 | 一份带 p50/p95/p99 的报告 + SLO 达标结论 |
| S3 运行时诊断 | `learn/03` 里的案例选 2 个做透，各一份排查记录（现象→假设→验证→数据→结论） |
| S4 发布与回滚 | 独立完成一次发布 + 一次回滚 |
| S5 面试表达 | 简历里每个 `___` 都填上**自己测出来**的数字，能扛三层追问 |

调研记录的模板沿用 `简历/01` §5（现象 / 假设 / 怎么验证 / 数据 / 结论）。
**"假设不成立"同样是有效结论**，必须写进记录。
