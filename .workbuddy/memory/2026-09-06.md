### 乐观锁方案重构（用户明确要求）
- `byte[] RowVersion` + `[Timestamp]` → **int Version + SQL 条件手动控制**，跨数据库
- 核心逻辑收敛在 `BaseRepository.ApplyOptimisticVersion(entity, expectedVersion)`：
  EF 原始值设为 expected、当前值 +1，配合 `IsConcurrencyToken` 生成
  `UPDATE ... SET Version=@expected+1 WHERE Id=@id AND Version=@expected`，0 行受影响 → `DbUpdateConcurrencyException` → 中间件转 409
- 全链路 DTO/Service/QueryRepo 从 base64 RowVersion 改为 int Version
- 迁移已重新生成（integer 类型，无 bytea 残留）
