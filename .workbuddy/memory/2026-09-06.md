- `byte[] RowVersion` + `[Timestamp]` → **int Version + SQL 条件手动控制**，跨数据库
- 核心逻辑收敛在 `BaseRepository.ApplyOptimisticVersion(entity, expectedVersion)`：
  EF 原始值设为 expected、当前值 +1，配合 `IsConcurrencyToken` 生成
