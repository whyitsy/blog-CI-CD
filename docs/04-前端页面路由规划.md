# 04-前端页面路由规划

> 文档版本：v1.0 | 技术栈：Vue3 + TS + Vite + Vue Router + Pinia + Naive UI + SCSS

## 1. 路由表

| # | path | 组件 | 说明 | 备注 |
|---|------|------|------|------|
| 1 | `/` | `views/HomeView.vue` | 首页：Hero 首屏 + 文章卡片列表 | 查询参数 `?page=2` 同步分页状态 |
| 2 | `/post/:id` | `views/PostDetailView.vue` | 文章详情 | 进入即调用详情接口（浏览量+1） |
| 3 | `/tags` | `views/TagsView.vue` | 标签墙（按钮+数量徽标） | |
| 4 | `/categories` | `views/CategoriesView.vue` | 分类墙（按钮+数量徽标） | |
| 5 | `/archive` | `views/ArchiveView.vue` | 归档时间轴 | |
| 6 | `/posts` | `views/PostListView.vue` | 通用结果列表页 | 复用文章卡片列表组件；query：`?tagId=&categoryId=&keyword=&page=` |

路由模式：`createWebHistory()`（需后端/nginx 兜底 history 回退）。
滚动行为：切换路由回到顶部；首页内锚点滚动（Hero 向下按钮 → `#post-list`）用 `scrollIntoView({ behavior: 'smooth' })`。

## 2. 页面结构

### 2.1 全局布局 `layouts/DefaultLayout.vue`
- **NavBar**（透明固定顶栏，滚动后可加毛玻璃背景变体）：Logo + 首页/标签/分类/归档 + 搜索按钮（打开 SearchModal）
- `<router-view />` + 滚动过渡
- **Footer**：建站天数、总字数、总浏览量、文章数（`GET /api/site/stats`）

### 2.2 首页 Hero `components/hero/HeroSection.vue`
- 全屏背景：`/src/assets/hero-bg.jpg`（缺失则纯色渐变兜底）
- 主文本：CSS 动画上下浮动（±6px，3s ease-in-out infinite）
- 副文本：`v-typewriter` 自定义指令（循环打字/删除，内容来自 `GET /api/site/config`）
- 向下按钮：浮动 ±12px + opacity 呼吸动画，点击滚到 `#post-list`
- 社交图标行：`GET /api/site/social-links`（GitHub/Bilibili 等外链）
- **所有动画包裹 `@media (prefers-reduced-motion: reduce)` 降级为静态**

### 2.3 文章卡片列表 `components/post/PostCardList.vue`
- 响应式栅格：`≥1200px` 三列 / `768–1199px` 两列 / `<768px` 单列（SCSS media query）
- `PostCard`：封面（空→占位图）、标题、分类、标签、发布日期、摘要（后端 Summary 字段）
- 骨架屏：Naive UI `NSkeleton`（卡片形状）
- 分页器：`NPagination`（页码同步到路由 query，刷新不丢状态）
- 两侧预留功能位：`<aside>` 占位插槽

### 2.4 搜索弹窗 `components/search/SearchModal.vue`
- 导航栏按钮触发；输入防抖 300ms → `GET /api/posts/search?keyword=`
- 结果复用精简卡片（标题 + 高亮摘要 + 日期）；点击跳详情页

### 2.5 归档页 `components/archive/TimelineList.vue`
- 自绘时间轴（年份节点 + 月份分组 + 文章行），数据来自 `GET /api/posts/archives`

## 3. 状态管理（Pinia stores）

| Store | 职责 |
|-------|------|
| `useSiteStore` | 站点配置、社交链接、Footer 统计（缓存于 store，避免重复请求） |
| `usePostStore` | 列表查询参数、分页状态、筛选（tag/category/keyword） |
| `useSearchStore` | 搜索弹窗开关、关键词、结果 |

## 4. API 层约定

- `src/api/http.ts`：基于 fetch/axios 封装，统一解包 `ApiResponse`（code≠0 时 throw 并 toast）
- `src/api/posts.ts` / `categories.ts` / `tags.ts` / `site.ts`：按模块组织
- 媒体资源直接拼后端 origin：`{VITE_API_BASE}/media/xxx.jpg`

## 5. 环境变量

```
VITE_API_BASE=http://localhost:5000   # 后端地址（开发）
```

## 6. 目录结构

```
Blog.Frontend/src/
├── api/            # http 封装 + 模块化接口
├── assets/         # hero-bg.jpg 等
├── components/
│   ├── hero/       # HeroSection、TypewriterText、ScrollDownButton
│   ├── post/       # PostCard、PostCardList、PostSkeleton
│   ├── search/     # SearchModal
│   ├── archive/    # TimelineList
│   └── common/     # TagBadge、EmptyState 等
├── directives/     # v-typewriter
├── layouts/        # DefaultLayout（NavBar + Footer）
├── router/         # index.ts（路由表 + 滚动行为）
├── stores/         # Pinia
├── styles/         # SCSS 变量、mixin、断点
├── types/          # 与后端 DTO 对齐的 TS 类型
└── views/          # HomeView / PostDetailView / TagsView / CategoriesView / ArchiveView / PostListView
```
